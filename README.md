# Anime Rangers X Wiki

Welcome to the Anime Rangers X Wiki - your comprehensive guide to the Anime Rangers X universe.

## About

This is the official wiki for Anime Rangers X, built with Next.js and deployed at animerangersx.wiki.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

## Deployment

This site is automatically deployed via GitHub Actions to production.
